## Cursor

PRD와 프로젝트 구조를 확인한 뒤 RED 테스트 설계표 4개를 작성했다.

### 1. C2C 추적표 (15행)

Parser, Registry, LengthUnit, Converter, Formatter, CLI 개념을 README-5.1/5.2 요구사항 및 SC-1~3, Mom Test 증거 #1~#3와 연결했다. RED Test Idea로 `B-PARSE-01`, `D-REG-01/02/03`, `D-CONV-01~04`, `D-OCP-01`, `B-FMT-01`, `B-CLI-01/02`, `B-ERR-01~04`를 매핑했다.

### 2. Given-When-Then 테스트 설계표 (16행)

| Test ID | 요약 |
|---------|------|
| D-REG-02 | register_defaults → meter/feet/yard 3단위 |
| D-REG-01 | register/get 분리 (inch 등록·조회) |
| D-REG-03 | RatioBasedLengthUnit to_meter/from_meter |
| D-CONV-01 | convert_to_all(2.5, "meter") |
| D-CONV-02 | convert_to_all(10, "feet") |
| D-CONV-03 | convert(5, "yard", "feet") |
| D-CONV-04 | convert(1, "feet", "yard") 교차 정확도 |
| D-OCP-01 | inch 등록 후 converter 무수정 변환 |
| B-PARSE-01 | parse("meter:2.5") |
| B-ERR-01 | 콜론 없는 형식 |
| B-ERR-04 | 비숫자 값 |
| B-ERR-02 | 음수 입력 |
| B-ERR-03 | unknown unit (cubit) |
| B-FMT-01 | TEXT 3줄 포맷 |
| B-CLI-01 | run("meter:2.5") golden master |
| B-CLI-02 | 오류 메시지 golden master |

Expected Failure: 스켈레톤 `NotImplementedError` 또는 음수 미구현 AssertionError.

### 3. 테스트 플랜

P0-1~P0-16 우선순위. 실행 순서: Domain(D-REG → D-CONV → D-OCP) → App(B-PARSE → B-ERR → B-FMT) → CLI(B-CLI).

### 4. ECB·Mock 점검

P0 전체 Mock 불필요. Domain은 실 UnitRegistry·실 비율, CLI는 `run(raw_input: str) -> str`로 input()/stdout mock 회피.

### RED 범위 경계

- 포함: meter/feet/yard, 파싱·검증, TEXT 출력, Registry OCP, run() golden master
- 제외(P1): ConfigLoader, 동적 등록 CLI, JSON/CSV/table

### 필수 8건 매핑 확인

B-PARSE-01, D-CONV-01, D-CONV-02, B-ERR-01, B-ERR-02, B-ERR-03, D-OCP-01, D-REG-01 모두 §2 설계표에 포함.
