## User

현재 프로젝트는 `UnitConverter.py`를 OCP/SRP/TDD 기반으로 개선하기 위한 Python 프로젝트다.

이번 작업 목표:
구현을 시작하지 말고, 아래 목표 아키텍처에 맞는 **하네스 구조만 생성**한다.

중요:

* 함수/클래스의 실제 비즈니스 로직을 구현하지 마라.
* 변환 계산 로직을 작성하지 마라.
* 입력 파싱 로직을 작성하지 마라.
* JSON/YAML 로드 로직을 작성하지 마라.
* 출력 포맷 변환 로직을 작성하지 마라.
* 테스트 본문을 완성하지 마라.
* 지금은 디렉터리, 파일, 클래스/함수 시그니처, TODO, docstring, pass, NotImplementedError 수준의 스켈레톤만 만든다.
* 기존 `UnitConverter.py`는 수정하지 마라.

생성할 목표 구조:

```
unit_converter/
├── domain/
│   ├── length_unit.py
│   ├── unit_registry.py
│   └── converter.py
├── infrastructure/
│   └── config_loader.py
├── app/
│   ├── input_parser.py
│   └── output_formatter.py
├── cli.py
└── tests/
    ├── test_converter.py
    └── test_cli.py
```

각 파일의 의도:

1. `unit_converter/domain/length_unit.py` — LengthUnit 타입/프로토콜/인터페이스만 정의. to_meter/from_meter 인터페이스. 실제 변환 계산은 TODO.
2. `unit_converter/domain/unit_registry.py` — 단위 등록/조회 Registry 스켈레톤. OCP 핵심. meter/feet/yard 등록은 TODO.
3. `unit_converter/domain/converter.py` — meter 기준 변환 Converter 스켈레톤. 파싱·포맷·설정 로드 담당 안 함.
4. `unit_converter/infrastructure/config_loader.py` — JSON/YAML ConfigLoader 스켈레톤. P1 확장 지점 TODO.
5. `unit_converter/app/input_parser.py` — `unit:value` Parser 스켈레톤. 형식·음수·없는 단위 검증 TODO.
6. `unit_converter/app/output_formatter.py` — text/json/csv/table Formatter 스켈레톤. P1 확장 지점 TODO.
7. `unit_converter/cli.py` — CLI 진입점. input_parser, registry, converter, formatter 조립 위치 표시.
8. `unit_converter/tests/test_converter.py` — Domain 테스트. 함수명만, 본문 pass 또는 pytest.skip.
9. `unit_converter/tests/test_cli.py` — Boundary/CLI 테스트. 함수명만, 본문 pass 또는 pytest.skip.

추가: 각 패키지에 `__init__.py`. `pyproject.toml`/`pytest.ini`는 현재 상태 확인 후 필요성만 보고.

스켈레톤 규칙: pass / NotImplementedError / TODO만. 테스트 통과 목표 없음. `UnitConverter.py` 건드리지 않음.

### 생성된 디렉터리 구조

```
unit_converter/
├── __init__.py
├── domain/
│   ├── __init__.py
│   ├── length_unit.py      # LengthUnit Protocol, RatioBasedLengthUnit
│   ├── unit_registry.py    # UnitRegistry (OCP 핵심)
│   └── converter.py        # LengthConverter, ConversionResult
├── infrastructure/
│   ├── __init__.py
│   └── config_loader.py    # ConfigLoader (P1)
├── app/
│   ├── __init__.py
│   ├── input_parser.py     # InputParser, ParsedInput
│   └── output_formatter.py # OutputFormatter, OutputFormat (P1)
├── cli.py                  # run(), main() 조립 지점
└── tests/
    ├── __init__.py
    ├── test_converter.py   # Domain 테스트 8개 (skip)
    └── test_cli.py         # Boundary/CLI 테스트 8개 (skip)
```

### 레이어별 책임 (스켈레톤 수준)

| 레이어 | 파일 | 책임 |
|---|---|---|
| Domain | `length_unit.py` | 단위 타입/프로토콜 정의 |
| | `unit_registry.py` | 단위 등록·조회 (OCP 확장 지점) |
| | `converter.py` | meter 기준 변환 계산만 |
| Infrastructure | `config_loader.py` | JSON/YAML 로드 (P1, TODO) |
| App | `input_parser.py` | `unit:value` 파싱 |
| | `output_formatter.py` | text/json/csv/table 출력 (P1, TODO) |
| CLI | `cli.py` | Parser → Registry → Converter → Formatter 조립 |

모든 구현 메서드는 `raise NotImplementedError` 또는 `pass` + TODO 주석만 포함.
